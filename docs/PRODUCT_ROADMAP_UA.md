# VARTA UA — рішення та дорожня карта

## Концепція
Єдиний персональний Telegram Mini App для Львова, з масштабуванням на інші міста без копіювання кодової бази. Орієнтир: 25 000 активних користувачів на місяць. Стартовий бюджет на розробку — 0 грн власною працею; безкоштовний хостинг не гарантує нульових витрат при зростанні.

## Уже реалізовано
- FastAPI + Leaflet-карта тривог, джерело Alerts.in.ua; радіус 5–150 км, Львівщина за замовчуванням.
- Сигнал при новій тривозі, поки вебсторінка відкрита; фонові сповіщення ще не реалізовані.
- Графіки електроенергії Львівщини за обраною чергою з незалежного OE_OUTAGE_DATA.
- У гілці feature/accounts-foundation: серверний API акаунтів, Telegram initData, PostgreSQL-моделі; ще не підключені база/фронтенд.

## Узгоджені функції, які додаватимемо
1. **Головна / «Мій Львів»**: обране місто, необов'язкова адреса, черга світла, персональні попередження, вода/тепло, місцеві події; усі повідомлення з часом, джерелом та ознакою актуальності.
2. **Тривоги**: карта всієї України з акцентом на Львівщині та радіусом 150 км; звук і Telegram-бот для фонових сповіщень. Не вигадувати координати БпЛА, маршрути, ETA чи відстані; не робити публічне оперативне відстеження повітряних цілей.
3. **Електроенергія**: графіки за чергою, за можливості надійний пошук черги за адресою; нагадування за 60 хвилин лише для актуальних однозначних графіків. Не плутати планове і фактичне відключення.
4. **Дороги**: затори, ДТП, ремонти, перекриття з перевірених джерел; цивільні користувацькі позначки з маркуванням «непідтверджено», строком дії та скаргами. Заборонені оперативні позначки ТЦК, поліції, блокпостів.
5. **Тематична стрічка**: місто, авто, спорт, рибалка, туризм тощо; підписки на теми, коментарі, реакції, позначена реклама. Не копіювати чужі повні статті без дозволу.
6. **Власні чати і профілі**: окремий VARTA-нік, профіль, міські/тематичні чати всередині Mini App. Безкоштовний аватар — порожній або звичайне фото. VIP/донат: аніме, мультяшні, анімовані й інтерактивні аватари, рамки, значки, подарунки.
7. **Свобода обговорень**: політична критика, сленг, матюки дозволені. Автоматичні антиспам/антишахрайські механізми, скарги, тимчасові обмеження, апеляції; без штатних модераторів, але критичні інциденти потребують можливості ручного розгляду.
8. **SOS**: компактна червона закладка з будь-якого екрана; перевірені фахівцями тексти/ілюстрації першої допомоги та безпечного виживання. SOS Lite — легкий офлайн-набір; відео окремо за бажанням, без обіцянки постійного кешу Telegram WebView. Без реклами у SOS.
9. **Монетизація**: Telegram Stars для цифрових товарів, VIP, разові покупки; локальна реклама, бізнес-профілі, партнерські акції/промокоди, платне оформлення спільнот. Без продажу адрес чи геолокації. Прогнози доходів — лише сценарії.
10. **Масштабування**: один бекенд, база акаунтів і код, конфігурації джерел та спільнот для кожного міста. Підготовка API для майбутнього Android/iOS застосунку.

## Пріоритети
- P0: не зламати поточну карту і графіки; перевірити джерела та стан Render.
- P1: PostgreSQL, Telegram initData, профілі, налаштування, резервні копії, rate limiting.
- P2: інтеграція акаунтів у Telegram Mini App, «Мій Львів», персональні сповіщення.
- P3: SOS Lite; стрічка та теми.
- P4: власні чати, скарги, антиспам.
- P5: дороги, вода, тепло (лише з надійними даними).
- P6: VIP/Stars, реклама, міські бізнес-профілі.
- P7: додавання інших міст конфігурацією, а не форками.

## Технічні принципи
- Залишаємо Python/FastAPI, HTML/JS і Leaflet, не переписуємо на інший стек без потреби.
- Не зберігати персональні дані лише у файловій системі безкоштовного Render.
- Telegram initData перевіряти тільки на сервері; секрети — лише в environment variables.
- Приватні адреси не публікувати; видалення акаунта й мінімізація даних.
- Нові можливості позначати як «заплановано», поки вони не реалізовані.
- Платні SOS/безпекові функції не вводити: екстрена інформація залишається безкоштовною.
